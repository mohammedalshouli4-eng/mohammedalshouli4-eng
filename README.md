## 🛠️ Tools | الأدوات

### [arabic-video-tools](https://github.com/mohammedalshouli4-eng/arabic-video-tools)
Local Windows tools for videos: transcription with Whisper, burned-in Arabic captions that read right to left, and cutting silences, all from a simple menu.

<div dir="rtl">

أدوات محلية للفيديو على Windows: تفريغ الكلام بـ Whisper، وحرق ترجمة عربية صحيحة من اليمين لليسار (مش مقلوبة)، وقص السكتات، وكله من قائمة بسيطة.
